# 2D Car Avoidance Game

An arcade-style endless driving game built with C++, GLFW, and OpenGL. Steer
through three lanes, avoid randomly generated traffic, and try to beat your
high score as the road gets faster.

## Controls

- **Left / Right arrow** or **A / D**: steer
- **R**: restart after a crash
- **Esc**: quit

## Build and run

On Windows, run `make win` from an MSYS2 environment with GCC and Make
installed. The executable is created in `build`.

On Linux, install the GLFW development package and run `make linux`.
